# یادداشت انتشار و آزمون نسخه 0.6.6

## اصلاح انجام‌شده

در نسخه 0.6.5، آدرس HTTP فایل PDF ثابت بدون تغییر داخل iframe صفحه HTTPS کارت قرار می‌گرفت. مرورگر این درخواست را به‌عنوان Mixed Content مسدود می‌کرد و قاب PDF سفید دیده می‌شد.

نسخه 0.6.6 آدرس‌های HTTP هم‌دامنه را هنگام نمایش و ذخیره تنظیمات به HTTPS تبدیل می‌کند. بنابراین تنظیم فعلی رویداد نیز بدون ذخیره مجدد اصلاح می‌شود. آدرس‌های دامنه‌های دیگر خودکار تغییر نمی‌کنند.

## محدوده تغییر

- هیچ جدول یا داده‌ای مهاجرت نمی‌شود.
- مسیر ثبت‌نام، بازیابی، صدور کارت، QR، OTP، پیامک و حضور تغییر نکرده است.
- تنظیمات و ثبت‌نام‌های موجود حفظ می‌شوند.

## آزمون پس از نصب

1. ZIP نسخه 0.6.6 را روی نسخه موجود جایگزین کنید؛ افزونه را حذف نکنید.
2. یک کارت موجود را در پنجره ناشناس بازیابی کنید.
3. بررسی کنید PDF پیش از کارت نمایش داده می‌شود و دکمه دانلود، آدرس HTTPS را باز می‌کند.
4. یک ثبت‌نام آزمایشی کامل انجام دهید و ایجاد کارت و پیامک را کنترل کنید.

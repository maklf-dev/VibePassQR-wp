# برنامه آزمون 0.5.1-alpha.1

## ۱. ارتقا

1. از دیتابیس و uploads پشتیبان بگیرید.
2. ZIP را روی نسخه 0.5.0 نصب و جایگزین کنید؛ افزونه را حذف نکنید.
3. نسخه نمایش‌داده‌شده در عیب‌یابی باید `0.5.1-alpha.1` باشد.
4. رویدادها، ثبت‌نام‌ها، QRها، پیامک‌ها و گزارش‌های قبلی باید باقی مانده باشند.

## ۲. غیرفعال‌شدن PDF تمپلیت

1. ویرایش یک رویداد را باز کنید.
2. بخش بارگذاری PDF و نگاشت مختصات نباید نمایش داده شود.
3. کارت را باز کنید؛ فقط دکمه چاپ کارت باید دیده شود.
4. چاپ باید طرح HTML پیش‌فرض افزونه را در سند مستقل باز کند.
5. لینک‌های کوتاه `/t/` و `/a/` باید همچنان کار کنند.

## ۳. حالت فقط کارت شخصی

1. در «مهمان‌ها و کارت‌های مستقل»، دسترسی معرف را روی «فقط کارت خودش» بگذارید.
2. ثبت‌نامی با حداقل دو مهمان بسازید.
3. با شماره یا لینک معرف بازیابی کنید؛ فقط کارت معرف باید دیده شود.
4. با شماره یا لینک هر مهمان بازیابی کنید؛ فقط همان مهمان باید دیده شود.
5. با تغییر دستی شناسه participant در URL نباید کارت مهمان دیگری نمایش داده یا چاپ شود.

## ۴. حالت گروهی قدیمی

1. دسترسی معرف را روی «کارت خودش و همه مهمان‌ها» بگذارید.
2. بازیابی معرف باید همه کارت‌ها و دکمه چاپ همه را نمایش دهد.
3. بازیابی مهمان همچنان باید فقط کارت همان مهمان را نمایش دهد.

## ۵. شماره مشترک

1. دو مهمان با یک شماره مجاز ثبت کنید.
2. بازیابی فقط با شماره باید درخواست کد پیگیری کند.
3. شماره همراه کد پیگیری مهمان اول فقط کارت مهمان اول را باز کند.
4. کد اشتباه باید پیام پیدا نشدن کارت را نمایش دهد.

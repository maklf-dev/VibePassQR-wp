# یادداشت انتشار 0.4.0-alpha.2

این نسخه مرحله دوم معماری پیامک است و مستقیماً روی `0.4.0-alpha.1` قابل نصب است. هیچ جدول یا داده قبلی حذف نمی‌شود.

## تغییرات اصلی

- تست اتصال پس از باز شدن صفحه «پیامک و اتصال» در پس‌زمینه اجرا می‌شود. نتیجه موفق سبز است و در خطا دکمه «تلاش مجدد» نمایش داده می‌شود.
- موجودی درگاه با جداکننده سه‌رقمی نمایش داده می‌شود.
- هر رویداد می‌تواند تنظیمات پیامک سراسری را به ارث ببرد یا برای هفت وضعیت، فعال‌سازی و محتوای مستقل داشته باشد.
- هر نوبت می‌تواند فقط پیامک «حضور موفق» و «ثبت تکراری» را مستقل از رویداد تنظیم کند.
- ثبت‌نام معرف و هر مهمان، پیامک مستقل دریافت می‌کند. `{name}`، `{tracking_code}` و `{card_link}` به همان کارت تعلق دارند و `{host_name}` نام معرف است.
- لینک پیامک مهمان فقط کارت همان مهمان را باز می‌کند. لینک معرف همچنان همه کارت‌های ثبت‌نام را نمایش می‌دهد.
- گزارش صف نام شخص، معرف/مهمان، رویداد و نوبت را نشان می‌دهد.

## ترتیب اعمال تنظیمات

اتصال، درگاه، توقف اضطراری و Worker همیشه سراسری‌اند. محتوای پیامک با ترتیب زیر انتخاب می‌شود:

1. تنظیم سراسری
2. تنظیم رویداد، اگر ارث‌بری خاموش باشد
3. تنظیم نوبت برای حضور موفق یا تکراری، اگر جایگزینی نوبت روشن باشد

## نکات ارتقا

- پیش از جایگزینی ZIP از دیتابیس و `wp-content/uploads` پشتیبان بگیرید.
- افزونه قبلی را حذف نکنید؛ ZIP جدید را جایگزین کنید.
- پس از ارتقا یک‌بار بخش مدیریت وردپرس را باز کنید تا مهاجرت افزایشی اجرا شود.
- وضعیت توقف صف و فعال‌بودن پیامک از نسخه قبلی حفظ می‌شود.

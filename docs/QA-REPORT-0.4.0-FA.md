# گزارش کنترل کیفیت بسته 0.4.0

## دامنه بررسی

- ارتقای افزایشی از 0.4.0-alpha.2
- ثبت‌نام، کارت، QR، مهمان، بازیابی، حضور اپراتوری و گزارش‌ها بدون تغییر قرارداد
- معماری Transport مستقل، صف پس‌زمینه و تاریخچه تلاش‌ها
- کتابخانه پترن و نگاشت متغیر در سطح سراسری، رویداد و نوبت
- آزمون مستقل اتصال، متن، پترن و لینک کارت
- عدم افشای کلیدها و اطلاعات اتصال در رابط یا گزارش

## کنترل‌های ایستا

- تطبیق نسخه فایل اصلی و ثابت `ECM_VERSION`
- کنترل ساختار ZIP و نبود فایل‌های موقت/سیستمی
- کنترل نحو JavaScript با Node.js
- جست‌وجوی کلیدهای خصوصی و داده‌های نمونه حساس
- کنترل استفاده از nonce و capability در عملیات مدیریتی جدید
- کنترل محدودیت طول و خالی نبودن پارامترهای پترن
- کنترل محدودیت پترن مالی به ثبت‌نام دارای پرداخت موفق

## محدودیت محیط ساخت

مفسر PHP در محیط بسته‌بندی در دسترس نبود؛ بنابراین lint اجرایی PHP در این محیط انجام نشد. فایل‌ها با کنترل ساختاری و مقایسه تغییرات بررسی شده‌اند. آزمون نهایی باید روی staging هم‌نسخه سایت با PHP 8.1 و WordPress فعلی اجرا شود. برنامه آزمون همراه بسته، مسیر دقیق تأیید را مشخص می‌کند.

## نتیجه مورد انتظار پذیرش

بسته زمانی برای فعال‌سازی خودکار پیامک پذیرفته است که آزمون اتصال GV، متن آزاد، پترن مالی، لینک معرف، لینک مهمان و اولویت تنظیم سراسری/رویداد/نوبت همگی روی staging موفق باشند.

# گزارش QA نسخه 0.5.0

## کنترل‌های خودکار

- تجزیه ساختاری همه فایل‌های PHP و JavaScript
- تطبیق نسخه هدر و ثابت افزونه
- برابری SHA-256 قالب همراه افزونه با PDF تأییدشده
- وجود هفت annotation قابل‌کلیک در قالب اصلی و خروجی بازنویسی‌شده توسط pdf-lib
- حفظ هر هفت لینک در تک‌صفحه و در هر صفحه خروجی گروهی سه‌صفحه‌ای
- کنترل رندر تصویری QR، نام، موبایل، شناسه و نوع بلیت روی نواحی نمونه فایل رسمی
- وجود جدول‌های نسخه قالب و توکن کوتاه و ایندکس‌های یکتا
- جداسازی scope کارت و حضور
- حفظ fallback برای QR و لینک‌های قدیمی
- پاک‌سازی توکن‌ها هنگام حذف سابقه و حفظ قالب‌های رویداد
- نبود دامنه، IP یا کلید API خصوصی در کد جدید
- سازگاری خواندن Blob با Safariهایی که `Blob.arrayBuffer()` ندارند
- درج نسخه‌های قالب بارگذاری‌شده در ZIP پشتیبان و گزارش فضای مصرفی آن‌ها

## کنترل لازم روی سایت آزمایشی

مهاجرت dbDelta، مجوز نوشتن uploads، Rewrite Rules، دانلود روی Safari و اسکن دوربین باید روی همان هاست وردپرس آزمایش شوند؛ این موارد به تنظیمات واقعی PHP، وب‌سرور و مرورگر وابسته‌اند.

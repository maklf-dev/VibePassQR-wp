# یادداشت انتشار Event Card Manager 0.3.0

این نسخه انتشار پایدار مبتنی بر نسخه تأییدشده `0.3.0-beta.2` است و برای ارتقای مستقیم طراحی شده است.

## تغییرات نهایی

- حذف حالت پرداخت نمایشی همیشه‌موفق
- افزودن وضعیت مستقل `offline_confirmed` برای ثبت بدون درگاه
- حفظ صدور کارت در حالت رایگان و بدون درگاه، بدون گزارش پرداخت بانکی ساختگی
- حذف ابزار ریست داده‌های آزمایشی از بسته انتشار
- خاموش‌کردن پیش‌فرض Support Log و پاک‌سازی لاگ‌های مرحله توسعه هنگام ارتقا
- توقف کنترل‌شده پیامک و حفظ صف‌های ارسال‌نشده
- حذف تنظیم قدیمی و بی‌اثر رفتار گروهی QR
- یکدست‌شدن رفتار QR: معرف همراه مهمان‌ها و مهمان به‌صورت مستقل
- بهینه‌سازی Query گزارش با پیش‌بارگذاری بسته‌ای به‌جای Query جدا برای هر ردیف
- تولید سند چاپ گزارش در بسته‌های ۵۰۰تایی برای جلوگیری از مصرف جهشی حافظه
- افزودن ایندکس‌های ترکیبی ثبت‌نام، حضور، شرکت‌کنندگان، رویدادها، پیامک و فایل‌ها
- کاهش Queryهای پنل اپراتور هنگام ثبت گروهی
- پاک‌سازی مستندات داخلی Alpha/Beta و اطلاعات محیط توسعه از ZIP
- حفظ قرارداد QR، کارت، کوکی دسترسی، شناسه‌ها، برگه‌ها و داده‌های نسخه‌های قبلی

## محدودیت‌های آگاهانه

- ارسال IPPanel تا تأمین مسیر خروجی با IP ایران متوقف است.
- درگاه بانکی واقعی نیازمند مشخصات حساب، callback و قرارداد سرویس‌دهنده است و در این بسته تنظیم نشده است.
- آزمون نهایی دوربین فیزیکی و عملکرد هاست باید در staging کارفرما انجام شود.

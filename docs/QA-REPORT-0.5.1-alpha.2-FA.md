# گزارش کنترل ساختاری 0.5.1-alpha.2

تاریخ: ۳ آبان ۱۴۰۵ / 2026-10-25

## نتیجه

همه ۲۲ کنترل خودکار این بسته موفق بوده‌اند.

## کنترل‌های انجام‌شده

- parse ساختاری تمام فایل‌های PHP و JavaScript
- تطبیق نسخه هدر افزونه و ثابت `ECM_VERSION`
- حفظ مسیرهای کوتاه کارت و حضور و توکن تصادفی ۱۲۸ بیتی
- حفظ لینک کوتاه کارت در پیامک
- نبودن renderer و کتابخانه موتور قدیمی PDF بلیت
- نبودن تنظیمات تمپلیت PDF و Endpoint آرشیو کارت PDF
- حفظ سیاست دسترسی کارت رویداد و محدودیت چاپ مهمان
- حفظ بازیابی امن شماره مشترک با کد پیگیری
- حذف عبارت درخواستی از عنوان کد پیگیری
- وجود تنظیم URL PDF ثابت در رویداد و اعتبارسنجی HTTP/HTTPS
- وجود نمایش درون‌صفحه‌ای و دکمه دانلود PDF قبل از کارت
- حفظ کارت HTML پیش‌فرض
- نبودن API Key و IP حساس گزارش‌شده در سورس توزیعی

## محدودیت کنترل محلی

این گزارش جایگزین تست روی وردپرس واقعی نیست. ذخیره تنظیم رویداد، پاسخ وب‌سرور فایل PDF، نمایش Safari و دانلود روی موبایل باید طبق برنامه آزمون همین نسخه در سایت آزمایش شوند.

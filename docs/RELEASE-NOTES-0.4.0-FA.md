# یادداشت انتشار Event Card Manager 0.4.0

این بسته، نسخه `0.4.0-alpha.2` تأییدشده را بدون تغییر قراردادهای کارت، QR، ثبت‌نام، مهمان، حضور، اپراتور و گزارش به نسخه 0.4.0 ارتقا می‌دهد. نصب باید به‌صورت جایگزینی ZIP روی افزونه موجود انجام شود؛ افزونه قبلی را حذف یا Uninstall نکنید.

## مرکز پیامک نهایی

- مسیر عملیاتی پیشنهادی: `واسط IPPanel SMS Pro GV`.
- Edge API برای هاست دارای IP ایران و عیب‌یابی رسمی باقی مانده است.
- WP‑SMS مسیر سازگاری ثانویه است.
- `اتصال مستقیم Legacy IPPanel` فقط در مرکز آزمون در دسترس است و قابل انتخاب به‌عنوان درگاه عملیاتی نیست.
- آزمون اتصال، متن آزاد، پترن و لینک واقعی کارت مستقل از درگاه ذخیره‌شده اجرا می‌شوند.
- موجودی فقط در نوار اصلی وضعیت و با جداکننده هزارگان نمایش داده می‌شود.

## پترن آماده

پترن زیر در ارتقا، در کتابخانه پترن‌ها ساخته می‌شود:

- شناسه: `registration_payment`
- کد: `is35i844i289qa9`
- `name={name}`
- `phone={phone}`
- `pay={payment_reference}`
- `date={payment_date}`

این پترن مالی است و ارسال خودکار آن فقط وقتی مجاز است که ثبت‌نام وضعیت پرداخت موفق و شماره تراکنش داشته باشد. هر مقدار پترن باید غیرخالی و حداکثر ۴۰ کاراکتر باشد. پترن فعلی متغیر لینک ندارد؛ آزمون لینک کارت با متن آزاد انجام می‌شود تا برای لینک، پترن اختصاصی تأیید شود.

## سازگاری و امنیت

- هیچ API Key، نام کاربری یا رمز پنل در HTML، JavaScript یا گزارش‌های خروجی قرار نمی‌گیرد.
- تنظیمات افزونه Gravity خوانده می‌شود اما در دیتابیس ECM کپی نمی‌شود.
- ارسال‌های خودکار همچنان از صف پس‌زمینه، تلاش محدود و ثبت تاریخچه هر تلاش استفاده می‌کنند.
- لینک معرف همه کارت‌های همان ثبت‌نام و لینک مهمان فقط کارت همان مهمان را بازیابی می‌کند.
- ارتقا هیچ پیامک paused قدیمی را خودکار آزاد نمی‌کند.

## نکته مهم نصب

پیش از ارتقا از دیتابیس و پوشه آپلودها نسخه پشتیبان بگیرید. پس از نصب، صفحه «پیامک و اتصال» را باز کنید، درگاه عملیاتی را روی واسط GV بگذارید، تنظیمات را ذخیره کنید و برنامه آزمون همراه بسته را اجرا کنید.

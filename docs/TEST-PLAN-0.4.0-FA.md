# برنامه آزمون نسخه 0.4.0

## آماده‌سازی

1. از دیتابیس و `wp-content/uploads` نسخه پشتیبان بگیرید.
2. ZIP را روی نسخه فعلی جایگزین کنید؛ نسخه قبلی را حذف نکنید.
3. در «پیامک و اتصال»، درگاه عملیاتی را `واسط IPPanel SMS Pro GV` انتخاب و تنظیمات را ذخیره کنید.
4. ارسال خودکار را تا پایان تست‌های دستی متوقف نگه دارید.

## آزمون ۱ — سلامت ارتقا

- رویدادها، نوبت‌ها، گزارش‌ها، کارت‌ها و پنل اپراتور را باز کنید.
- انتظار: همه داده‌های قبلی باقی بمانند، نسخه 0.4.0 نمایش داده شود و خطای PHP/دیتابیس دیده نشود.

## آزمون ۲ — وضعیت اتصال

- وارد «پیامک و اتصال» شوید.
- انتظار موفق: نوار اصلی سبز شود، پیام «اتصال افزونه واسط موفق بود» را نشان دهد و موجودی فقط یک‌بار با قالبی مانند `26,014,327 ریال` نمایش داده شود.
- انتظار خطا: نوار قرمز و دکمه «تلاش مجدد» نمایش داده شود.

## آزمون ۳ — متن آزاد

- در مرکز آزمون، درگاه GV، شماره خودتان و «متن آزاد» را انتخاب کنید.
- انتظار: پیامک برسد و یک نتیجه موفق در بخش ۵۰ ارسال اخیر یا نتیجه آزمون دیده شود؛ تنظیم درگاه عملیاتی عوض نشود.

## آزمون ۴ — پترن مالی

- روش را «پترن» انتخاب کنید.
- پترن کتابخانه `ثبت‌نام مالی — دوره فیزیک سلامت نسل Z` را انتخاب کنید.
- شماره خط ارسال را مطابق تنظیم موفق GV وارد کرده باشید.
- مقادیر آزمون برای `name`، `phone`، `pay` و `date` را غیرخالی و زیر ۴۰ کاراکتر نگه دارید.
- انتظار: پیامک مطابق متن تأییدشده پنل برسد. در صورت رد، کد HTTP/خطا در نتیجه آزمون دیده شود و هیچ کلیدی افشا نشود.

## آزمون ۵ — لینک واقعی کارت

- یک ثبت‌نام کامل پیدا کنید و ID آن را در آزمون «لینک واقعی کارت» وارد کنید.
- برای معرف، Participant ID را خالی بگذارید. انتظار: لینک پس از تأیید بازیابی، کارت معرف و همه مهمانان را باز کند.
- برای مهمان، Participant ID همان مهمان را وارد کنید. انتظار: لینک فقط کارت همان مهمان را باز کند.
- لینک یک‌بارمصرف است؛ برای آزمون دوباره، پیام جدید بسازید.

## آزمون ۶ — تنظیم سراسری، رویداد و نوبت

- در تنظیمات سراسری یک وضعیت را روی پترن کتابخانه قرار دهید.
- در یک رویداد، ارث‌بری را خاموش و پترن همان وضعیت را جداگانه انتخاب کنید.
- در یک نوبت، override پیامک حضور را فعال و پترن یا متن مستقل تعیین کنید.
- انتظار: اولویت اجرا `نوبت ← رویداد ← سراسری` باشد و سایر رویدادها تغییر نکنند.

## آزمون ۷ — صف و ایمنی

- با ارسال خودکار متوقف، یک رخداد پیامکی ایجاد کنید. انتظار: رکورد `paused` ذخیره شود و پیام ارسال نشود.
- توقف را بردارید ولی گزینه آزادسازی paused قبلی را روشن نکنید. انتظار: پیام‌های قبلی آزاد نشوند.
- فقط در محیط کنترل‌شده، آزادسازی را انتخاب کنید و نتیجه صف را بررسی کنید.

## گزارش موردنیاز در صورت خطا

نام آزمون، زمان محلی، نتیجه مورد انتظار، نتیجه واقعی، تصویر صفحه، ID ثبت‌نام/Participant و ID رکورد پیامک را ارسال کنید. API Key، رمز پنل و شماره کامل کاربران را در گزارش قرار ندهید.

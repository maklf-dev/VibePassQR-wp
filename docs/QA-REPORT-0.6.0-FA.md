# گزارش کنترل ساختاری 0.6.0

## کنترل‌های انجام‌شده روی بسته

- Parse همه فایل‌های PHP با parser سازگار PHP 8
- کنترل syntax فایل‌های JavaScript عمومی، مدیریتی و اپراتور
- کنترل نسخه افزونه و مسیر مهاجرت افزایشی دیتابیس
- کنترل وجود جدول OTP، seed پترن و پاک‌سازی رکوردهای منقضی
- کنترل عدم ذخیره کد خام در جدول پیامک، تلاش‌ها و diagnostics
- کنترل مصرف یک‌باره، قفل هم‌زمانی verify و محدودیت درخواست/تلاش
- کنترل حفظ مسیر بازیابی قدیمی هنگام غیرفعال‌بودن OTP
- کنترل جلوگیری از retry مدیریتی رکورد OTP با payload پوشانده‌شده
- کنترل بسته ZIP و فهرست فایل‌ها

## محدودیت کنترل محلی

ارسال واقعی پیامک، رفتار افزونه واسط، تحویل اپراتور مخابراتی و رندر دقیق قالب فعال وردپرس فقط روی سایت مقصد قابل تأیید است. مراحل لازم در `TEST-PLAN-0.6.0-FA.md` آمده است.

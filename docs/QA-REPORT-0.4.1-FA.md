# گزارش کنترل نسخه 0.4.1

تاریخ ساخت: 2026-10-19

## کنترل‌های انجام‌شده

- پارس ساختاری همه ۲۳ فایل PHP و ۶ فایل JavaScript بدون خطا
- کنترل توازن ساختار CSS و بررسی نحوی JavaScript پنل مدیریت
- تطبیق نسخه هدر افزونه و ثابت داخلی با 0.4.1
- کنترل مهاجرت انتخاب‌های قدیمی پترن به روش ارسال مستقل هر اعلان
- کنترل ذخیره قالب معرف/مهمان در سطوح سراسری، رویداد و نوبت
- کنترل وجود متغیر لینک کارت و کشف پویای فیلدهای فرم
- کنترل لینک کوتاه ۱۲۸بیتی و پذیرش لینک‌های ۶۴ کاراکتری قبلی
- کنترل ستون و ایندکس یکتای موبایل رویداد و پیام خطای قابل تنظیم
- کنترل مسیر گزارش پیامک، فیلترها، CSV و ثبت آزمون‌های دستی
- کنترل نبودن API Key ارائه‌شده، دامنه سایت و IP هاست در بسته

نتیجه کنترل آفلاین: همه کنترل‌ها موفق بودند.

## مرز کنترل

محیط ساخت به وردپرس و دیتابیس واقعی سایت متصل نبود؛ بنابراین نصب واقعی، اجرای `dbDelta`، ارسال پیامک و نمایش مرورگر باید طبق بخش آزمون پذیرش روی نسخه پشتیبان یا Staging سایت انجام شود. وضعیت ارسال خودکار موجود در ارتقا تغییر نمی‌کند.

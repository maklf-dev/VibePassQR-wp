# یادداشت انتشار 0.5.1-alpha.2

این بسته روی نسخه `0.5.1-alpha.1` و نسخه‌های قبلی به‌صورت جایگزینی نصب می‌شود و اطلاعات موجود را حذف نمی‌کند.

## تغییرات این مرحله

- عبارت «در صورت اشتراک شماره» از عنوان کد پیگیری فرم بازیابی حذف شد.
- برای هر رویداد یک تنظیم مستقل «PDF ثابت قبل از کارت» اضافه شد.
- URL فایل از تنظیمات همان رویداد خوانده می‌شود و فایل داخل بسته افزونه کپی یا برای هر ثبت‌نام تکثیر نمی‌شود.
- PDF در صفحه کارت، قبل از QR و کارت HTML اصلی نمایش داده می‌شود.
- دکمه دانلود مستقیم PDF و راهنمای جایگزین برای مرورگرهای فاقد نمایش داخلی اضافه شد.
- چون ثبت‌نام موفق و بازیابی هر دو به صفحه کارت می‌رسند، نمایش PDF در هر دو مسیر یکسان است.
- موتور قدیمی ساخت کارت از روی PDF همچنان غیرفعال است؛ کارت اصلی همان طرح HTML پیش‌فرض و قابل چاپ افزونه باقی مانده است.

## تنظیم

از مسیر «کارت و رویداد ← رویدادها ← ویرایش رویداد ← کارت و بازیابی»، لینک کامل HTTPS فایل را در «PDF ثابت قبل از کارت» وارد و رویداد را ذخیره کنید. خالی‌گذاشتن این فیلد نمایش PDF را برای همان رویداد غیرفعال می‌کند.

## سازگاری

هیچ جدول یا شناسه‌ای تغییر نکرده است. ثبت‌نام‌ها، مهمان‌ها، QRها، لینک‌های کوتاه، پیامک‌ها، حضورها، نقش‌ها و گزارش‌های قبلی حفظ می‌شوند.

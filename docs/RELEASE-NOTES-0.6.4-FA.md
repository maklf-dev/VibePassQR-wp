# یادداشت انتشار و آزمون Event Card Manager 0.6.4

## هدف نسخه

این اصلاحیه ثبت شماره موبایل نامعتبر را پیش از هرگونه ذخیره اطلاعات مسدود می‌کند و گزارش روزانه را برای تشخیص مسیر و علت خطا دقیق‌تر می‌سازد. ارتقا افزایشی است و هیچ تنظیم، رویداد، ثبت‌نام، کارت، پیامک یا سابقه حضوری را حذف یا بازنشانی نمی‌کند.

## قانون شماره موبایل

- ورودی معرف و مهمان باید یک شماره موبایل معتبر ایران باشد.
- قالب نمایش فرم `09xxxxxxxxx` و دقیقاً ۱۱ رقم است.
- ارقام فارسی و عربی پذیرفته و پیش از ذخیره به رقم انگلیسی تبدیل می‌شوند.
- مقدار خالی فقط برای فیلد تلفن غیراجباری مجاز است.
- حروف، فاصله داخلی، نشانه‌ها، شماره ثابت و شماره کوتاه یا بلند رد می‌شوند.
- کنترل مرورگر صرفاً برای تجربه بهتر است؛ کنترل قطعی دوباره در سرور اجرا می‌شود و با غیرفعال‌کردن JavaScript قابل دورزدن نیست.

## گزارش روزانه نسخه دوم

فایل روزانه فقط درخواست‌ها و عملیات متعلق به Event Card Manager را ثبت می‌کند و شامل این بخش‌هاست:

- تعداد صفحه‌ها، فرم‌ها، AJAX و عملیات افزونه به تفکیک مسیر
- وضعیت HTTP، زمان پاسخ، حافظه اوج و تعداد کوئری به شکل تجمیعی
- میانگین، بیشینه و تخمین بازه‌ای P95 و P99
- حداکثر ۲۴ درخواست کند یا خطادار اخیر و حداکثر ۳۰ خطای عملیاتی اخیر
- شناسه درخواست برای اتصال رخدادهای مرتبط، رویداد، نوبت، کاربر مدیریتی و مؤلفه خطا
- ثبت مسیر بدون Query String در خطوط لاگ تشخیصی، همراه با شناسه همان درخواست و روش HTTP
- وضعیت صف پیامک و OTP، کیفیت داده‌های ثبت‌شده و مشخصات فنی کم‌حجم محیط
- تعداد و زمان انتظار قفل فایل برای ارزیابی سربار خود گزارش‌گیری

شماره موبایل، IP خام، QR، کد بلیت، داده فرم، متن پیامک، API Key و رمزها در این فایل نوشته نمی‌شوند. اندازه فایل به ۱ مگابایت محدود است و آرایه‌های جزئی نیز سقف ثابت دارند.

## چک‌لیست آزمون پذیرش

1. افزونه را از بخش افزونه‌های وردپرس روی نسخه قبلی بارگذاری و جایگزین کنید؛ افزونه قبلی را حذف یا Uninstall نکنید.
2. یک رویداد آزمایشی با فیلد تلفن و در صورت نیاز فیلد مهمان باز کنید.
3. با `09123456789` ثبت‌نام کنید؛ انتظار: ثبت موفق و ذخیره شماره استاندارد.
4. با `۰۹۱۲۳۴۵۶۷۸۹` ثبت‌نام کنید؛ انتظار: ثبت موفق و نرمال‌سازی خودکار.
5. با `abcdefghijk`، `0912abc6789`، شماره ۱۰ رقمی و شماره ۱۲ رقمی امتحان کنید؛ انتظار: پیام «شماره موبایل معتبر نیست» و عدم ساخت ثبت‌نام یا پیامک.
6. همین چهار حالت نامعتبر را برای شماره یک مهمان آزمایش کنید؛ انتظار مشابه است و هیچ کارت مهمانی ساخته نمی‌شود.
7. یک ثبت‌نام معتبر با پیامک فعال انجام دهید؛ انتظار: گردش قبلی ثبت‌نام، کارت و پیامک بدون تغییر کار کند.
8. یک بار OTP صحیح، OTP اشتباه و ارسال مجدد را آزمایش کنید.
9. در پنل اپراتور یک کد معتبر را بررسی و حضور را ثبت کنید؛ سپس ثبت تکراری را آزمایش کنید.
10. از «کارت رویداد ← نگهداری و عیب‌یابی» گزارش روزانه را دانلود کنید. فایل باید `ecm-daily-activity-v2` و بخش‌های `routes`، `performance`، `operation_results`، `recent_errors`، `slow_requests`، `writer` و `system_snapshot` را داشته باشد.
11. داخل JSON برای یک شماره واقعی، متن پیامک، API Key یا کد QR جست‌وجو کنید؛ هیچ‌کدام نباید وجود داشته باشند.

## نکته عملیاتی

دکمه «حذف گزارش امروز» فقط فایل تجمیعی همان روز را پاک می‌کند و شمارنده‌های آن روز از صفر آغاز می‌شوند. برای تحلیل کامل یک روز، ابتدا فایل را دانلود کنید و تا پایان همان روز آن را حذف نکنید.

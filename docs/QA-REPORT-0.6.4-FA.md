# گزارش کنترل ساختاری Event Card Manager 0.6.4

## مرجع ارتقا

- بسته مرجع: `event-card-manager-0.6.3(1).zip`
- SHA-256 مرجع: `6ea330e85c741f7dec4d7a675630b343ee396455e68571bfde820c1802fcdffe`
- روش ارتقا: جایگزینی مستقیم فایل‌های افزونه، بدون Uninstall و بدون بازنشانی داده

## کنترل‌های انجام‌شده

- پارس کامل ۲۶ فایل PHP با PHP Parser سازگار با PHP 8: بدون خطای syntax
- کنترل syntax تمام فایل‌های JavaScript با Node.js: بدون خطا
- کنترل ساختار ZIP و وجود تنها یک پوشه ریشه افزونه
- بررسی نبود Access Key، Authorization Token و کلید نمونه کاربر در بسته
- بررسی ثابت‌ماندن نام افزونه، مسیرها، shortcodeها، نام جدول‌ها و قراردادهای کارت/QR
- بررسی اینکه اعتبارسنجی سرور قبل از درج ثبت‌نام، هویت، مهمان و صف پیامک اجرا می‌شود
- بررسی وجود دفاع دوم در سازنده مهمان، مستقل از کنترل فرم
- بررسی محدودیت اندازه و تعداد رکوردهای جزئی گزارش روزانه
- بررسی عدم ثبت IP خام، شماره تلفن، QR، داده فرم، متن پیامک و اطلاعات اتصال در گزارش روزانه

## دامنه کنترل

این گزارش، کنترل ایستا و ساختاری بسته است. آزمون واقعی ارسال پیامک، OTP، مرورگر Safari/iOS، دیتابیس هاست و رفتار تحت بار باید پس از نصب روی محیط وردپرس انجام شود. چک‌لیست عملی این آزمون‌ها در `RELEASE-NOTES-0.6.4-FA.md` قرار دارد.

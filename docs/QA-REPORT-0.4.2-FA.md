# گزارش کنترل نسخه 0.4.2

## کنترل‌های انجام‌شده

- تجزیه ساختاری تمام فایل‌های PHP و JavaScript
- تطبیق نسخه هدر افزونه و ثابت داخلی با 0.4.2
- ذخیره و بازیابی سیاست شماره تکراری مهمان برای هر رویداد
- کنترل رویدادمحور بودن بررسی شماره معرف و مهمان
- حذف کامل `guest_max` از رابط فرم‌ساز، JavaScript و پردازش عمومی
- استفاده انحصاری از سقف مهمان رویداد
- مهاجرت نام مستقل شرکت‌کننده و استفاده از آن در کارت، اپراتور و گزارش‌ها
- جداسازی عملیات حذف بازه‌ای و ریست کامل سابقه
- پوشش جداول وابسته و پاک‌سازی هویت‌های بدون شرکت‌کننده
- بررسی نبود کلید API، دامنه و IP واقعی در بسته

## نتیجه

تمام کنترل‌های ساختاری خودکار عبور کرده‌اند. آزمون نهایی مهاجرت دیتابیس، ثبت هم‌زمان و عملیات حذف باید ابتدا روی نسخه آزمایشی سایت و با بکاپ انجام شود.

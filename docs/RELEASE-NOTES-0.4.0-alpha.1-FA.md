# یادداشت انتشار Event Card Manager 0.4.0-alpha.1

این نسخه مرحله اول بازگشت پیامک به پروژه است و روی نسخه پایدار 0.3.0 ساخته شده است. هدف آن تأیید مسیر واقعی ارسال روی سایت شما، بدون تغییر رفتار ثبت‌نام، کارت، QR، مهمان، حضور، اپراتور و گزارش‌هاست.

## تغییر اصلی

هسته پیامک دیگر به یک API مشخص وابسته نیست. Event Card Manager رخداد، گیرنده، متن، صف و گزارش را مدیریت می‌کند و یک Transport قابل تعویض فقط مسئول تحویل پیام است.

Transportهای این نسخه:

- `gv_bridge`: مسیر اصلی آزمون؛ فراخوانی متد عمومی افزونه IPPanel SMS Pro GV که تست داخلی آن روی سایت موفق بوده است.
- `edge`: مسیر قبلی Edge API با همان عیب‌یابی شبکه و نگهداری امن Access Key.
- `wp_sms`: مسیر سازگاری اختیاری برای WP‑SMS؛ ارسال پترن روی این مسیر در این نسخه فعال نیست.

## صف و گزارش

- ثبت‌نام و حضور برای ارسال پیام منتظر پاسخ پنل نمی‌مانند.
- Worker یک‌دقیقه‌ای، دسته‌های محدود صف را پردازش می‌کند.
- هر کار یک بار به‌صورت اتمیک claim می‌شود تا اجرای هم‌زمان Cron باعث ارسال تکراری نشود.
- تلاش‌های ناموفق قابل تکرار با فاصله افزایشی هستند.
- نتیجه هر تلاش، درگاه، زمان پاسخ و کد خطا جدا ذخیره می‌شود.
- آخرین وضعیت اتصال و موجودی به‌صورت خلاصه و بدون اطلاعات محرمانه نگهداری می‌شود.

## امنیت

- رمز و نام کاربری افزونه واسط در ECM ذخیره یا در خروجی گزارش نمایش داده نمی‌شود.
- واسط GV فقط با دامنه‌ای که با `https://` آغاز شود اجازه ارسال دارد.
- شماره کامل، متن پیام و رمز در فایل Support Log ثبت نمی‌شوند.
- Access Key مسیر Edge همچنان از `wp-config.php` یا گزینه رمز‌شده خوانده می‌شود.

## سازگاری ارتقا

- نسخه روی 0.3.0 و نسخه‌های توسعه‌ای قبلی به‌صورت جایگزینی ZIP نصب می‌شود.
- شناسه‌های ثبت‌نام و شرکت‌کننده، QR، کارت، برگه‌ها، نقش‌ها و تنظیمات فعلی حفظ می‌شوند.
- فعال/غیرفعال و متوقف/درحال‌اجرای پیامک هنگام ارتقا تغییر نمی‌کند.
- صف قبلی حذف نمی‌شود و با برداشتن توقف نیز خودکار آزاد نخواهد شد. آزادسازی همه پیام‌های قدیمی نیازمند انتخاب صریح گزینه مربوط است؛ ارسال مجدد یک ردیف نیز آن را به درگاه فعلی منتقل می‌کند.

## محدوده این مرحله

این نسخه برای تأیید Transport، تست اتصال، تست ارسال و کارکرد صف آماده شده است. تنظیم مستقل قالب‌ها و وضعیت‌های پیامک برای هر رویداد و هر نوبت، پیامک جداگانه مهمان‌ها، داشبورد تحلیلی کامل پیامک و بهینه‌سازی ارسال انبوه مرحله بعدی هستند و پس از تأیید این بسته روی سایت اجرا می‌شوند.

# گزارش کنترل کیفیت VibePassQR 0.7.0-alpha.5

## آزمون‌هایی که واقعاً انجام شده‌اند

- اجرای مجدد تمام آزمون‌های Mock نسخه alpha.4: **۱۴۳ بررسی موفق**.
- اضافه‌شدن **۳۷ بررسی** مستقل جدید: AES-GCM payload با AAD، جلوگیری از دستکاری، نگهداری غیرمتنی داده‌ها، کنترل شورت‌کد کلیدی/غیرکلیدی، مجوز و قفل هم‌زمانی ویرایش، عدم تغییر شماره موبایل، ممنوعیت ویرایش پس از بررسی، چرخش کد پیگیری و تاریخچه بدون داده شخصی، و محافظ Classic.
- جمع: **۱۸۰ بررسی Mock موفق**. این‌ها آزمون واحد و ایزوله هستند؛ نه شبیه‌سازی کامل مرورگر یا تراکنش واقعی دیتابیس.
- `php -l` برای تمام فایل‌های PHP در بسته و `node --check` برای JavaScriptها بررسی می‌شود؛ نتیجه در خروجی بسته‌بندی ثبت خواهد شد.
- مسیرهای `class-ecm-public.php` و `class-ecm-tickets.php` با alpha.4 مقایسه شدند و بدون تغییر باقی مانده‌اند.

## تست‌های انجام‌نشده

- درخواست واقعی admin-post.php، nonce ناشناس، مسیر کوکی و Redirect در مرورگر.
- هم‌زمانی و Rollback واقعی InnoDB، صدور کارت، SMTP/SMS provider واقعی، بررسی آپلود فایل واقعی و Staging محیط WordPress.
- تست Android/iOS و مهمان‌ها با JavaScript واقعی/دسترسی‌پذیری.
- Profiling ترافیک زیاد، تست بار و سازگاری ۲۷ افزونه دیگر سایت.

نتیجه: برای **Staging با نظارت** مناسب به عنوان کاندیدای آزمون، نه برای Production. عدد ۱۸۰ فقط تعداد Checkهای ایزوله است و درصد اطمینان عملیاتی را تعیین نمی‌کند.

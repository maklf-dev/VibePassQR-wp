# یادداشت انتشار Event Card Manager 0.4.2

## تغییرات این نسخه

1. در ویرایش هر رویداد، بخش «کنترل شماره‌های تکراری همین رویداد» دارای دو سیاست مستقل است:
   - جلوگیری از تکرار شماره معرف؛
   - اجازه ثبت شماره تکراری برای مهمان.
2. بررسی تکراری‌بودن شماره فقط در همان رویداد انجام می‌شود. شماره ثبت‌شده در یک رویداد می‌تواند در رویداد دیگر دوباره استفاده شود.
3. نام هر کارت مهمان به‌صورت مستقل ذخیره می‌شود؛ بنابراین دو مهمان با شماره مشترک همچنان نام، QR و کارت جدا دارند.
4. سقف مهمان از ردیف‌های فرم‌ساز حذف شده است. تنها مقدار «حداکثر مهمان هر ثبت‌نام» در بخش «مهمان‌ها و کارت‌های مستقل» معتبر است.
5. ابزار نگهداری دو عملیات مستقل دارد:
   - حذف کامل داده‌های عملیاتی در یک بازه تاریخ؛
   - ریست کامل تمام سوابق عملیاتی افزونه.

## محدوده ریست کامل

ریست کامل ثبت‌نام‌ها، شرکت‌کنندگان، حضورها، پیامک‌ها، تلاش‌های ارسال، فایل‌های آرشیوی و لاگ‌های عملیاتی را حذف می‌کند. تعریف رویدادها، نوبت‌ها، دسترسی اپراتورها، تنظیمات، نقش‌ها و برگه‌های وردپرس حفظ می‌شوند.

هر دو عملیات حذف برگشت‌ناپذیرند و عبارت تأیید مستقل دارند. قبل از استفاده، ZIP تاریخچه و بکاپ دیتابیس تهیه شود.

## نکته بازیابی شماره مشترک

اگر شماره معرف و مهمان مشترک باشد، بازیابی با شماره تلفن ابتدا کارت‌های معرف را در نظر می‌گیرد. اگر یک شماره فقط برای چند مهمان استفاده شده باشد، آخرین کارت واجد شرایط مهمان بازیابی می‌شود. معرف همیشه می‌تواند تمام کارت‌های ثبت‌نام خودش را دریافت کند.

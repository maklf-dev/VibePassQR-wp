# گزارش کنترل کیفیت 0.4.0-alpha.2

## کنترل‌های بسته

- نسخه فایل اصلی و ثابت `ECM_VERSION`: `0.4.0-alpha.2`
- مهاجرت افزایشی دیتابیس با `dbDelta`
- حفظ جدول‌ها، شناسه‌ها، QRها و تنظیمات نسخه قبل
- عدم درج API Key، نام کاربری یا رمز افزونه واسط در HTML و گزارش‌ها
- تست نحوی JavaScript با Node.js
- بررسی ساختار PHP با parser مستقل
- بررسی فایل ZIP و مسیر ریشه افزونه
- جست‌وجوی کلید و رمز احتمالی در بسته نهایی

## مرز تست محیطی

ارسال واقعی، موجودی واقعی، Cron هاست، HTTPS دوربین و رفتار مرورگر Safari باید روی staging یا سایت اصلی آزموده شوند؛ این موارد به سرویس و محیط وردپرس وابسته‌اند.

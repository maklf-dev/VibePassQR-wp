# گزارش کنترل کیفیت Event Card Manager 0.4.0-alpha.1

## مبنا و دامنه

- مبنا: بسته نهایی 0.3.0 با SHA-256 برابر `ba1b4385a1620db49759b87011daac49fcb943c37cbf1129e4ff3151be85f6a7`
- دامنه تغییر: لایه پیامک، مهاجرت افزایشی دیتابیس پیامک، نمایش وضعیت درگاه، نگهداری/پشتیبان و مستندات
- فایل‌های عمومی ثبت‌نام، کارت، QR، مهمان، بازیابی، اپراتور، حضور و گزارش‌ها بازنویسی نشده‌اند.

## تطبیق با افزونه واسط

کد افزونه ارسالی `IPPanel SMS Pro GV 2.4.0` بررسی شد. اتصال ECM با امضای واقعی متدهای عمومی زیر منطبق است:

- `GFIPPANELSMS_Pro::credit( true )`
- `GFIPPANELSMS_Form_Send::Send( $to, $message, $from, $form_id, $entry_id )`

پاسخ موفق این افزونه رشته `OK` است و تست اعتبار، موجودی ریالی برمی‌گرداند. ECM این دو پاسخ را نرمال می‌کند و به هیچ property خصوصی یا فایل داخلی افزونه وابسته نیست.

## کنترل‌های انجام‌شده

- تحلیل نحوی ۲۳ فایل PHP با parser مستقل: بدون خطای syntax یا node ناقص
- بررسی نحوی ۶ فایل JavaScript با Node.js: موفق
- تطابق نسخه هدر و ثابت افزونه با `0.4.0-alpha.1`: موفق
- جست‌وجوی Access Key افشاشده، Authorization ثابت و رمز hard-coded: موردی پیدا نشد
- کنترل ساختار ارتقا: جدول و ستون‌های جدید فقط با `dbDelta` اضافه می‌شوند
- کنترل حذف کامل: جدول تلاش‌ها و snapshot جدید در Uninstall مدیریت شده‌اند
- کنترل پشتیبان: جدول تلاش‌های پیامک به خروجی نگهداری اضافه شده است
- کنترل رقابت Worker: claim هر پیام با UPDATE شرطی انجام می‌شود و فقط یک Worker اجازه ارسال می‌گیرد
- کنترل صف قدیمی: پیام‌های paused بدون انتخاب صریح مدیر آزاد نمی‌شوند
- کنترل امنیت واسط: endpoint غیر HTTPS پیش از ارسال رد می‌شود
- کنترل سازگاری: PHP حداقل 8.0 و WordPress حداقل 6.5 حفظ شده است

## موارد نیازمند آزمون روی سایت

محیط ساخت، WordPress/PHP اجرایی و حساب واقعی IPPanel در اختیار ندارد؛ بنابراین موارد زیر باید با برنامه آزمون همراه بسته روی سایت تأیید شوند:

- مهاجرت واقعی دیتابیس MySQL با prefix سایت
- شناسایی کلاس‌های افزونه GV در ترتیب بارگذاری واقعی وردپرس
- دریافت موجودی و ارسال واقعی متن آزاد
- ارسال پترن با کد و پارامترهای حساب شما
- اجرای WP‑Cron یا cron واقعی هاست و عبور `queued` به `accepted`
- دریافت پیام روی تلفن و اندازه‌گیری تأخیر

انتشار خودکار پیامک برای همه کاربران تا تکمیل این آزمون توصیه نمی‌شود. تست دستی مستقل از کلید فعال‌سازی پیامک است و می‌تواند در حالت توقف کنترل‌شده انجام شود.

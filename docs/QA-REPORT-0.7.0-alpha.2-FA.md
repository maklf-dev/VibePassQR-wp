# QA نسخه 0.7.0-alpha.2

## آزمون‌های اجراشده

- PHP lint تمام فایل‌های PHP بسته؛ بدون خطای Syntax.
- Node.js syntax check روی `assets/js/workflow-preview.js`؛ موفق.
- Smoke test همراه با Mock وردپرس/دیتابیس برای هسته 0.7.0-alpha.1 و چک‌های جدید مرحله ۳؛ موفق.
- صحت عدم اجرای `DROP`, `DELETE`, `TRUNCATE` در مهاجرت Workflow؛ بررسی ایستا.
- بررسی تفاضلی فایل‌های آلفا۱ و آلفا۲؛ تغییرات محدود به بوت‌استرپ، پیکربندی رویداد، سرویس Flow و پیش‌نمایش جدید.
- اطمینان از عدم تغییر مستقیم مسیر عمومی `registration_shortcode` و فایل‌های Tickets / SMS / Reports / Attendance؛ بررسی ایستا.
- آزمون‌های منفی CSS، توکن داخل attribute و عدم پیکربندی مسیر خصوصی در Mock؛ موفق.

## آزمون‌های انجام‌نشده (الزامی پیش از انتشار واقعی)

- نصب در WordPress و اجرای Schema واقعی روی MariaDB؛ آزمون دو مدیر هم‌زمان.
- دریافت واقعی آپلود HTTP با `is_uploaded_file`، بررسی سطح دسترسی هاست و سیاست بکاپ فایل‌های خصوصی.
- امنیت و بررسی دقیق HTML/CSS با فیلتر واقعی `wp_kses_post` وردپرس، مرورگر موبایل و حالت‌های متنوع فرم.
- آزمون کامل Workflow با رویداد دارای مهمان، فیلد چندانتخابی، تراکنش ردشده و بازیابی پس از قطع ارتباط.
- هرگونه تأیید رسمی یا صدور کارت/QR/ارسال SMS (در این فاز عمداً وجود ندارد).

**وضعیت:** پیش‌نمایش مدیریتی برای Staging؛ عدم تأیید نصب Production.

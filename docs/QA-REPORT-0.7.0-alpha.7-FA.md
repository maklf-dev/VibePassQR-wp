# گزارش کنترل کیفیت VibePassQR 0.7.0-alpha.7

## آنچه در محیط جاری واقعاً اجرا شد

| بررسی | نتیجه | محدوده |
|---|---|---|
| زنجیره تست فازهای قبلی (`workflow-phase6-smoke.php`) | ۱۸۰ PASS | WordPress و دیتابیس Mock، بخشی با OpenSSL واقعی |
| تست ایزوله گزارش و Import (`test-phase7.php`) | ۳۸ PASS | Mock / Validator؛ سازگار با اضافه شدن جدول attendance |
| تست ایمنی فاز هشتم (`test-phase8.php`) | ۹۹ Assertion موفق | Engine غلط/جدول مفقود/رد قبل از درج، محدودسازی درخواست، No-Cache |
| PHP Lint | بدون خطای Syntax | تمام فایل‌های PHP افزونه |
| JavaScript Syntax | بدون خطای Syntax | فایل‌های JS افزونه |
| سلامت ZIP و تطابق شناسه افزونه | باید در بسته نهایی تأیید شود | بررسی محلی ساختار آرشیو |

**جمع کل ۳۱۷ بررسی موفق** شامل Assertion و Mock است؛ **این عدد ۳۱۷ آزمون End-to-End مستقل نیست**.

## نقص‌های تشخیص‌داده‌شده و اصلاح‌شده

- عدم بررسی Engine جدول‌های مورد استفاده در صدور Workflow قبل از ثبت تراکنشی.
- عدم بررسی `attendance` در وابستگی‌های ورود گروهی.
- سقف شبکه بسیار باز برای درخواست‌های OTP، با امکان تعویض کوکی مرورگر.
- عدم اعمال سیاست No-Cache پیش از رندر شورت‌کد پیگیری مستقل.

## هنوز اثبات نشده

- صحت `START/COMMIT/ROLLBACK` و `GET_LOCK` روی MariaDB واقعی
- ساخت رسمی کارت، QR و مهمان پس از تأیید در سایت واقعی
- دریافت پیامک OTP و اعلان‌های Workflow در درگاه واقعی
- ورود XLSX با PHP دارای `ZipArchive` و `SimpleXML`
- عملکرد بارگذاری عکس با iOS/Android و خطاهای HTTP
- سازگاری نسخه PHP 8.1 واقعی، WordPress 6.9.11، سایر افزونه‌ها و LiteSpeed
- مقایسه رکوردهای قبل/بعد، Load/Profiling روی Staging و هم‌زمانی دو مدیر

**حکم QA:** قابل استفاده برای آزمایش کنترل‌شده در Staging؛ **برای نصب روی سایت اصلی آماده نیست**.

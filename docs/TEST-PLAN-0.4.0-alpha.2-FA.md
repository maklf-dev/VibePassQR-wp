# برنامه آزمون 0.4.0-alpha.2

## ۱. ارتقا و سلامت عمومی

1. ZIP را روی نسخه قبلی نصب و جایگزین کنید.
2. رویدادهای قبلی، نوبت‌ها، گزارش‌ها، کارت‌ها و پنل اپراتور را باز کنید.
3. انتظار: داده‌ها باقی مانده باشند و خطای دیتابیس یا PHP دیده نشود.

## ۲. تست خودکار اتصال

1. وارد «Event Card Manager ← پیامک و اتصال» شوید.
2. انتظار موفق: نوار بالای صفحه سبز، پیام تأیید اتصال و موجودی با قالبی مانند `1,234,567 ریال` نمایش داده شود.
3. انتظار خطا: نوار قرمز و دکمه «تلاش مجدد» نمایش داده شود؛ با کلیک، تست تازه اجرا شود.

## ۳. تنظیم رویداد

1. در یک رویداد آزمایشی، «تنظیمات سراسری پیامک استفاده شود» را خاموش کنید.
2. روش را متن آزاد قرار دهید، ثبت‌نام و حضور را فعال و متن‌ها را با نام رویداد مشخص ذخیره کنید.
3. انتظار: رویداد دیگر همچنان از متن سراسری استفاده کند و فقط رویداد آزمایشی متن جدید را در صف ثبت کند.

## ۴. تنظیم نوبت

1. داخل نوبت آزمایشی، بخش «پیامک اختصاصی این نوبت» را باز و جایگزینی را فعال کنید.
2. برای حضور موفق متن متفاوتی وارد کنید و رویداد را ذخیره کنید.
3. انتظار: حضور در همین نوبت متن نوبت را بگیرد؛ پیام زودهنگام/دیرهنگام همچنان از رویداد یا سراسری بیاید.

## ۵. معرف و مهمان

1. ثبت‌نامی با یک معرف و حداقل دو مهمان با شماره‌های متفاوت بسازید.
2. انتظار: سه رکورد مستقل در گزارش پیامک با نام درست و نقش معرف/مهمان ثبت شود.
3. لینک مهمان را باز کنید و دکمه بازیابی را بزنید.
4. انتظار: فقط کارت همان مهمان دیده شود.
5. لینک معرف را باز کنید.
6. انتظار: کارت معرف و همه مهمانان دیده شود.

## ۶. گزارش موردنیاز برای بازخورد

برای هر خطا این موارد را ارسال کنید: نام تست، نتیجه مورد انتظار، نتیجه واقعی، تصویر صفحه، زمان محلی آزمون، ID رکورد پیامک و فایل عیب‌یابی. API Key، رمز پنل و شماره کامل کاربران را ارسال نکنید.
